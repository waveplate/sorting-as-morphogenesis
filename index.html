The "Cell-View" Logic

FOR EACH CELL (running in parallel):
  1. Look at Left Neighbor
  2. Look at Right Neighbor
  IF type is "Ascending":
    If value < Left: Swap Left!
    If value > Right: Swap Right!
  IF type is "Descending":
    If value > Left: Swap Left!
    If value < Right: Swap Right!
